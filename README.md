# ML & DL 学习项目说明

## 一、项目概述

本仓库是一个以 Python 为基础的机器学习（Machine Learning）、深度学习（Deep Learning）和自然语言处理（NLP）为主题的学习项目。项目内容覆盖了从经典机器学习算法到 PyTorch 深度学习模型，再到文本处理与情感分析等实战案例，适合用于 AI 入门学习、课程实践和知识复习。

仓库的主要目录如下：

- `ML/`：机器学习相关内容
- `DL/`：深度学习相关内容
- `NLP/`：自然语言处理相关内容
- `runs/`：训练日志与 TensorBoard 产物
- `README.md`：项目入口说明

## 三、机器学习模块（`ML/`）

`ML/` 目录主要包含传统机器学习算法与案例分析，内容涵盖：

1. 线性回归
   - 一元和多元线性回归
   - 正规方程法求解
   - 线性回归与房价预测案例

2. 模型评估与优化
   - 交叉验证
   - 准确率、召回率、精确率、F1 分数等指标
   - 梯度下降与学习率影响

3. 分类算法
   - KNN 分类与回归
   - 决策树相关内容
   - 随机森林
   - 聚类任务：KMeans

4. 聚类与无监督学习
   - KMeans 模型实现
   - 肘方法确定最佳 K 值
   - 客户案例分析

5. 案例文件
   - `ML/day02/鸢尾花识别.ipynb`
   - `ML/day02/正规方程式解决问题.ipynb`
   - `ML/day03/cart-泰坦尼克号生存预测-分类问题.py`
   - `ML/day04/KMeans模型.py`
   - `ML/day04/随机森林实现泰坦.py`

从这些文件可以看出，`ML/` 部分更偏向算法理解和实战演练，适合从基础机器学习知识入手。

## 四、深度学习模块（`DL/`）

`DL/` 目录以 PyTorch 为核心，重点学习深度学习的基础与提高能力。主要内容包括：

1. 张量基础
   - 创建张量
   - 随机张量与线性张量
   - 基本张量操作

2. 神经网络基础
   - 全连接网络
   - 线性层、激活函数、损失函数
   - 前向传播与反向传播

3. 常见网络结构
   - CNN 卷积神经网络
   - RNN / LSTM / GRU
   - 词嵌入层

4. 图像与分类任务
   - 图像分析案例
   - 图片分类实践
   - 数据集与模型训练

5. 优化与正则化
   - 学习率调节
   - 正则化方法
   - BatchNorm / Dropout 等思想

6. 典型文件
   - `DL/day01/torch创建张量.py`
   - `DL/day03/构造神经网络.py`
   - `DL/day04/网络优化.ipynb`
   - `DL/day06/图像分析案例.py`
   - `DL/day07/词嵌入层.ipynb`

从文件内容可以看出，`DL/` 目录具有较强的工程实践属性，适合学习从基本网络到深度学习模型构建的完整流程。

## 五、自然语言处理模块（`NLP/`）

`NLP/` 目录聚焦文本处理和序列模型，主要包括：

1. 文本预处理
   - 分词
   - 词表构建
   - 填充与截断

2. 词嵌入与序列模型
   - Embedding 层
   - RNN
   - LSTM
   - GRU

3. 文本分类任务
   - 酒店评论情感分析
   - 正负面情绪分类
   - 文本分类数据处理和评估

4. FastText 与迁移学习
   - `fasttext_train.py`
   - `hotel_analys.py`
   - 模型训练与文本特征提取

5. 大模型与 AI 应用
   - `ai_chat.py`
   - 自动填充、问答与文本生成相关脚本

6. 典型文件
   - `NLP/day02/fasttext_train.py`
   - `NLP/day02/hotel_analys.py`
   - `NLP/day03/lstm_demo.py`
   - `NLP/day03/rnn_demo.py`
   - `NLP/day03/hotel_pre.py`
   - `NLP/day05/ai_chat.py`

这部分内容体现了从传统 NLP 到现代文本处理和 AI 应用的连续学习路径。

## 七、学习路线建议

建议按照以下顺序学习：

1. Python 基础与数据处理
2. 机器学习基础算法
3. 评估指标与模型选择
4. 深度学习基础（PyTorch 张量与网络）

7. 文本分类与情感分析
8. 进一步扩展到大模型应用

## 八、总结

本仓库是一个比较完整的 AI 学习项目，覆盖了：

- 经典机器学习
- 深度学习与 PyTorch
- 自然语言处理
- 文本分类和模型训练
- 视觉与序列数据的应用实践

它适合用于学习、实验、复盘和项目积累。通过该仓库，学习者可以从基础算法逐步过渡到现代深度学习与 NLP 技术，形成比较系统的知识体系。
